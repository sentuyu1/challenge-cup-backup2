# 统计推断

## 核心知识点
- 点估计：矩估计、极大似然估计（MLE）、无偏性、有效性
- 区间估计：置信区间（正态均值/方差、比例）
- 假设检验：原假设/备择假设、显著性水平、拒绝域、p 值
- 两类错误：α（弃真）、β（取伪）、功效 = 1-β

## 典型题型与解法
- 求 MLE：写出似然函数，取对数求导
- 求置信区间：按分布选分位数，写出双端点 [a, b]
- 假设检验：写检验统计量 → 临界值/p 值 → 比较 → 结论
- 求功效：先写拒绝域，β = P(未落入拒绝域 | H1 真)

## 核验要点
- 假设检验最终答案必须含六要素：H0/H1、统计量值、临界值、比较、"拒绝/不拒绝"、实际结论
- 置信区间必须同时给下限和上限，不得只给单侧
- 标准差与方差不要混淆（区分 σ 与 σ²）
- p 值 < α 时拒绝 H0
