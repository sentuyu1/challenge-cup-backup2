# 离散数学

## 核心知识点
- 组合计数：排列组合、二项式系数、生成函数、递推
- 图论：树、欧拉/哈密顿、匹配、染色
- 初等数论：整除、同余、素数、LTE 升幂引理、乘法阶
- 组合博弈、鸽巢原理、容斥原理

## 典型题型与解法
- 计数：分情况 + 容斥 + 生成函数，小规模枚举验证
- 图论：度数、连通性、最大流最短路
- 数论：模运算、φ 函数、Carmichael 函数 λ(n)
- 博弈：必胜/必败态倒推、Sprague-Grundy、Nim 异或

## 核验要点
- 计数先小规模（n=2,3,4）枚举与公式对照，再外推
- 对称因子只乘一次；口径（固定起点 vs 总数）用小例标定
- 含 0 口径：自然数含 0 时 0 常满足条件，漏计恰好少 1
- 不可能性先证伪：小规模可行则原论证有误
