# 高等代数

## 核心知识点
- 矩阵运算、行列式、秩、逆矩阵；初等变换
- 特征值、特征向量、特征多项式、对角化
- 线性空间、基与维数、线性变换；二次型与标准形
- 极小多项式、对称多项式、二元域状态

## 典型题型与解法
- 求特征值/特征向量：解特征方程，回代求特征向量
- 判断可对角化：几何重数 = 代数重数
- 求逆矩阵：初等行变换或伴随矩阵
- 二次型化标准形：配方法或正交变换

## 核验要点
- 矩阵乘法不可交换，注意顺序
- 特征值之和 = 迹，之积 = 行列式（可作核验）
- Jordan 标准形：`A.jordan_form()` 返回 (P, J)，标准形是第二个返回值
- `A.diagonalize()` 返回 (P, D)；`sp.solve` 返回列表，取值前判空
