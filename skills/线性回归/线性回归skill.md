# 线性回归

## 核心知识点
- 一元/多元线性回归、OLS 最小二乘估计
- 回归系数显著性检验（t 检验）、模型显著性（F 检验）
- R²、SSE、SSR、SST、自由度、标准误
- 残差分析、异方差、自相关、多重共线性（VIF）

## 典型题型与解法
- 求回归方程：正规方程 (X'X)β = X'y
- 求标准误、t 统计量、F 统计量
- 区间预测与均值响应区间
- 写出 ANOVA 方差分析表

## 核验要点
- 最终答案必须保留命名字段：标准误、SSE、自由度、检验统计量、临界值、ANOVA 表
- 非参数回归 ≠ 非线性回归（相近概念区分）
- 写出中间矩阵 X、X'X、X'y
- R² = SSR/SST = 1 - SSE/SST
