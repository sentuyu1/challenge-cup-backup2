# 运筹学解题要点

## 适用与边界

涵盖线性规划、整数规划、运输与指派、网络优化、排队论、存储论、动态规划、博弈与决策。纯组合博弈、图论证明归离散数学；回归与参数检验归线性回归/统计推断。

## 通用核验

- 先定目标方向（max/min）、约束方向、变量符号与非负性，画出可行域。
- 可行解不等于最优解，必须验完检验数或对偶界才能下结论。
- 最优性最可靠的判据是强对偶：若原问题可行解 x 与对偶可行解 y 满足 cᵀx = bᵀy，则两者都是最优。
- 符号约定要统一：检验数用 σ_j = c_j − c_B B⁻¹a_j 还是 z_j−c_j，最优性不等号方向会跟着变。

## 线性规划

**单纯形法**：化标准形 → 定初始基可行解 → 算检验数 → 最大正检验数进基 → 最小比值定出基 → 主元消去，循环。

**对偶转换**（最容易错的地方）：
- 原 max 且约束 ≤ ↔ 对偶变量 ≥ 0；原 max 且约束 = ↔ 对偶变量自由。
- 原变量 ≥ 0 ↔ 对偶约束 ≥；自由变量 ↔ 对偶等式约束。
- 系数矩阵转置：对偶约束系数是原约束系数的转置 Aᵀ。
- 写完用弱对偶 cᵀx ≤ bᵀy 验算：若原、对偶都可行却 cᵀx > bᵀy，方向一定写反了。

**互补松弛**：最优点处 y_i·(b_i − Σa_ij x_j) = 0 且 x_j·(Σa_ij y_i − c_j) = 0。严格不等式的约束 → 对应对偶变量为 0；对偶变量 > 0 → 对应约束取等。

## 运输问题

**最小元素法求初始解**：
1. 每轮取剩余运价表最小 c_ij，令 x_ij = min(剩余供应, 剩余需求)。
2. 划去被满足的行或列（同时满足时只划一个，另一留 0）。
3. 重复到供需全满。产销平衡时基变量应为 m+n−1 个，退化补 0。

**位势法判优**：基变量满足 u_i + v_j = c_ij，令 u_1 = 0 解出位势；非基变量检验数 σ_ij = c_ij − u_i − v_j，全 ≥ 0 即最优（min 问题）。

**判分硬性要求**：最终答案必须逐项列出全部基变量取值（如 x_11=3、x_13=2、x_22=4，其余为 0）并给出总运费；只报总运费算未完成。求解后自检：各行和 = 供应量，各列和 = 需求量，总运费 = Σc_ij x_ij。

## 整数规划

LP 松弛只给界（min 问题 z_LP ≤ z_IP）。分支定界要选非整数变量分支、求解子问题、剪枝，终止时须说明当前整数可行解与上下界相等。把松弛解当整数答案是常见错误。

## 非线性规划（KKT）

对 min f(x) 且 g_i(x)≤0、h_j(x)=0：∇f + Σμ_i∇g_i + Σλ_j∇h_j = 0，μ_i g_i = 0，μ_i ≥ 0。对不等式约束分类讨论 μ_i=0 或 g_i=0。若 f 凸、g_i 凸、h_j 仿射，KKT 点即全局最优。

## 动态规划

逆序递推：f_k(s_k) = min/max { v_k(s_k,u_k) + f_{k+1}(s_{k+1}) }，f_{n+1}=0。划分阶段、定义状态与决策、写状态转移、从末阶段向前递推、顺推得最优策略。

## 图与网络

- **Dijkstra**：d(s)=0 其余 ∞ → 选未标号最小 d(u) 永久标号 → 更新邻点 d(v)=min(d(v), d(u)+w(u,v)) → 循环。
- **最大流（Ford-Fulkerson）**：零流起，标号法找增广路（前向弧未饱和/后向弧有流），汇点标号则沿路增流，无增广路为止。
- **最大流最小割**：流值 ≤ 割容量；残余网络中 s 可达点集 S 构成最小割，流值 = 割容量。

## 排队论

先核对到达率、服务率、稳定条件（ρ=λ/μ<1）和系统容量，再选模型；不稳定不能套稳态均值。

- M/M/1：P_0=1−ρ，L=ρ/(1−ρ)，L_q=ρ²/(1−ρ)，W=L/λ，W_q=L_q/λ。
- M/M/c：P_0 = [Σ_{n=0}^{c−1}(cρ)^n/n! + (cρ)^c/(c!(1−ρ))]⁻¹，L_q = (cρ)^c ρ P_0/(c!(1−ρ)²)，L = L_q + cρ。

## 存储论（EOQ）

TC(Q) = KD/Q + hQ/2，Q* = √(2KD/h)，TC* = √(2KDh)。由 TC'(Q)=0 导出，二阶导 > 0 保证凸。

## 博弈与决策

- 2×2 混合策略用无差异原理：令两条期望线相等解出 p、q。
- 鞍点：a_{ij*} ≤ a_{i*j*} ≤ a_{i*j} 对所有 i,j。
- 分割-选择博弈逆向归纳：后动者必选大堆，先动者最大化 min(a,b)，即尽量均分。
- 决策树矩形节点选分支、圆节点取期望，从叶到根逆推。

## 通用建模六步

问题理解 → 变量定义 → 目标函数 → 约束识别 → 参数赋值 → 模型定型（LP/NLP/IP/DP/排队）。

## 最优性验证方法

| 方法 | 适用 | 操作 |
|------|------|------|
| 检验数非正 | LP(max) | 所有 σ_j ≤ 0 |
| 强对偶 | LP | 构造对偶解使 cᵀx*=bᵀy* |
| KKT | NLP | 验证全部 KKT 条件 |
| 凸性+KKT | 凸规划 | KKT 点即全局最优 |
