# 运筹学解题技能手册

## 领域边界与路由约定

- 本手册覆盖线性规划、整数规划、非线性规划、运输问题、网络优化、排队论、存储论、调度、决策以及运筹博弈。
- 不覆盖：纯组合博弈与图论证明划归离散数学；统计回归与参数检验划归线性回归或统计推断。
- 核验原则：先明确目标方向、全部约束、可行性与最优性；调度和分配类题目必须给出完整方案与总成本。

## 客观题判别与全局核验

- 解线性规划前先确认目标方向、约束方向、变量非负性以及可行域；可行解不代表最优解，必须继续检查检验数或对偶界。
- 强对偶定理是判断最优性的可靠工具：若能找到原问题可行解 $x$ 和对偶问题可行解 $y$ 满足 $c^T x = b^T y$，则 $x$ 与 $y$ 分别是各自问题的最优解。
- 单纯形表中的检验数、进基变量和离基变量要使用同一套符号约定；若采用 $z_j-c_j$ 的写法，最优性不等号方向也要相应翻转。
- 运输问题的初始解只保证供需平衡，并不自动最优；先核对所有行列和，再用位势法或闭回路改善检验。出现退化时要补零基变量，不能漏算自由度。
- 整数规划中 LP 松弛只提供界；分支定界终止时必须说明当前整数可行解与上下界已经相等。直接把松弛解当整数答案是常见错误。
- 排队模型要先核对到达率、服务率、稳定条件（如 $\rho<1$）和系统容量，再选 M/M/1、M/M/c 或有限源公式；稳定条件不满足时不能套用稳态均值。

## 易错点与口径约定

- 运输问题求初始基可行解时，最终答案必须逐一列出全部基变量取值（例如 $x_{11}=3,\ x_{13}=2,\ x_{22}=4,\ x_{23}=1$，其余 $x_{ij}=0$），并给出初始总运费；只报总运费按未完成处理。
- 最小元素法流程：每轮取剩余运价表里最小的 $c_{ij}$，令 $x_{ij}=\min(\text{剩余供应},\text{剩余需求})$，划去被满足的行或列；产销平衡时基变量应有 $m+n-1$ 个，退化时补 0。
- 求解后自检：各行的分配之和等于供应量，各列的分配之和等于需求量，总运费 $\sum c_{ij}x_{ij}$ 与逐项相加结果一致。
- 对偶问题方向转换：原问题 max 对应偶问题 min，约束方向与变量符号的对应关系极容易记反；写完用弱对偶不等式 $c^T x \le b^T y$ 快速验算——若原、对偶均可行却出现 $c^T x > b^T y$，说明对偶方向写反了。
- 等式约束与自由变量：原问题中的等式约束对应无符号限制的对偶变量，反之亦然；很多人习惯性加上 $\ge 0$ 而丢分。

## 模块一：线性规划

### 核心概念

决策变量、目标函数、约束条件、可行域、基可行解、对偶问题、影子价格。

### 图解法（两个变量）

1. 画出约束直线，标清不等式方向，确定可行域
2. 画目标函数等值线，沿改进方向平移
3. 交点即为最优解

### 单纯形法

1. 引入松弛变量化成标准形
2. 确定初始基可行解
3. 计算检验数 $\sigma_j=c_j-\mathbf{c}_B B^{-1}\mathbf{a}_j$
4. 最优性判据：所有 $\sigma_j\le0$（max 问题）；否则取最大正 $\sigma_j$ 进基
5. 用最小比值规则 $\theta=\min\{b_i/a_{ik}\mid a_{ik}>0\}$ 定出基
6. 主元消去，重复迭代

### 对偶问题构建

原 max 约束 $\le$ 对应对偶变量 $\ge0$；原变量 $\ge0$ 对应对偶约束 $\ge$。

### 弱对偶定理

对任意原/对偶可行解，有 $c^T x\le b^T y$（max 原问题）。

### 强对偶定理

若原问题有有限最优解 $x^*$，则对偶问题也有有限最优解 $y^*$，且最优值相等：$c^T x^* = b^T y^*$。

### 互补松弛条件

在最优点处：
$$y_i^* \cdot (b_i - \sum_j a_{ij} x_j^*) = 0,\qquad x_j^* \cdot (\sum_i a_{ij} y_i^* - c_j) = 0$$

- 原问题某约束为严格不等式（有松弛）时，对应对偶变量必为 0
- 对偶变量严格为正时，对应原约束必取等号
- 互补松弛可用于由原解反推对偶解

### 考试高频陷阱

- 方向转换：原 max → 对偶 min，不要搞反；原 min → 对偶 max
- 约束与变量的对应：max 问题 + $\le$ 约束 → 对偶变量 $\ge 0$；max 问题 + $=$ 约束 → 对偶变量自由
- 容易漏掉转置：对偶约束的系数矩阵是原系数矩阵的转置 $A^T$
- 互补松弛不是"互斥"：对偶变量 > 0 且约束取等是允许的，乘积为零才是条件

## 模块二：运输问题

### 最小元素法

1. 找最小 $c_{ij}$，分配 $\min(a_i,b_j)$
2. 更新供需，划去已满行/列
3. 重复直到所有供需满足
4. 基变量应为 $m+n-1$ 个

### 位势法

- 基变量满足 $u_i+v_j=c_{ij}$，令 $u_1=0$ 解出所有位势
- 非基变量检验数 $\sigma_{ij}=c_{ij}-u_i-v_j$
- 全 $\ge0$ 即为最优（min 问题）

## 模块三：整数规划

LP 松弛下界：$z_{LP}^*\le z_{IP}^*$（min 问题），因为 $X_{IP}\subset X_{LP}$。

分支定界：求解 LP 松弛 → 选非整数变量分支 → 求解子问题 → 剪枝。

## 模块四：非线性规划

### KKT 条件

对 $\min f(\mathbf{x})$ 且 $g_i(\mathbf{x})\le0,\ h_j(\mathbf{x})=0$：
$$\nabla f+\sum\mu_i\nabla g_i+\sum\lambda_j\nabla h_j=0,\quad \mu_i g_i=0,\quad \mu_i\ge0$$

### KKT 充分性（凸规划）

若 $f$ 凸、$g_i$ 凸、$h_j$ 仿射，则 KKT 点就是全局最优解。

### 解题步骤

1. 写出 Lagrange 函数
2. 列平稳性、原始可行、对偶可行、互补松弛条件
3. 对不等式约束分类讨论（$\mu_i=0$ 或 $g_i=0$）
4. 求解并验证

## 模块五：动态规划

逆序递推基本方程：
$$f_k(s_k)=\min/\max_{u_k}\{v_k(s_k,u_k)+f_{k+1}(s_{k+1})\},\quad f_{n+1}=0$$

步骤：划分阶段、定义状态与决策、写状态转移、从末阶段向前递推、顺推得最优策略。

## 模块六：图论与网络优化

### Dijkstra 最短路

1. 初始化 $d(s)=0$，其余 $\infty$
2. 选未标号最小 $d(u)$，永久标号
3. 更新邻点：$d(v)=\min\{d(v),d(u)+w(u,v)\}$
4. 重复直到目标点标号

### Ford-Fulkerson 最大流

1. 从零流开始
2. 标号法找增广路径（前向弧未饱和 / 后向弧有流）
3. 汇点标号则沿路径增流
4. 无增广路为止

### 最大流最小割定理

任意流值 ≤ 任意割容量。算法终止时残余网络中 $s$ 可达点集 $S$ 构成最小割，流值 = 割容量。

## 模块七：排队论

### M/M/1（$\rho=\lambda/\mu<1$）

| 指标 | 公式 |
|------|------|
| $P_0$ | $1-\rho$ |
| $L$ | $\rho/(1-\rho)$ |
| $L_q$ | $\rho^2/(1-\rho)$ |
| $W$ | $L/\lambda=1/(\mu-\lambda)$ |
| $W_q$ | $L_q/\lambda$ |

### M/M/c（$\rho=\lambda/(c\mu)<1$）

$$P_0=\left[\sum_{n=0}^{c-1}\frac{(c\rho)^n}{n!}+\frac{(c\rho)^c}{c!(1-\rho)}\right]^{-1}$$
$$L_q=\frac{(c\rho)^c\rho}{c!(1-\rho)^2}P_0,\quad L=L_q+c\rho$$

## 模块八：存储论

### EOQ 模型

$$TC(Q)=\frac{KD}{Q}+\frac{hQ}{2},\quad Q^*=\sqrt{\frac{2KD}{h}},\quad TC^*=\sqrt{2KDh}$$

由 $TC'(Q)=0$ 推出 $Q^*$，$TC''(Q)=2KD/Q^3>0$ 保证凸。

## 模块九：博弈论

### 2×2 混合策略

设行玩家策略 $(p,1-p)$，列玩家 $(q,1-q)$。用无差异原理：令两条期望线相等解出 $p,q$。

### 鞍点条件

$(i^*,j^*)$ 为鞍点 ⟺ $a_{ij^*}\le a_{i^*j^*}\le a_{i^*j}$ 对所有 $i,j$。

### 分割-选择博弈

- Player 2 面对两堆 $(a,b)$ 必选较大一堆：$u_2=\max(a,b)$
- Player 1 预见到此，最大化自己所得：$u_1=n-\max(a,b)=\min(a,b)$
- 最优策略是尽量均分；均衡时 Player 1 使 $\min(a,b)$ 最大化而非总数最大化

## 模块十：决策论

### EMV 准则

$$EMV_i=\sum_j p_j r_{ij}$$

选择 $EMV$ 最大的方案。

### 决策树

矩形节点为决策节点（选分支），圆形节点为概率节点（取期望），从叶到根逆推。

## 最优性验证方法

| 方法 | 适用 | 操作 |
|------|------|------|
| 检验数非正 | LP(max) | 所有 $\sigma_j\le0$ |
| 强对偶 | LP | 构造对偶解使 $c^Tx^*=b^Ty^*$ |
| KKT 条件 | NLP | 验证全部 KKT 条件 |
| 凸性+KKT | 凸规划 | KKT 点即全局最优 |
